# Townly Website (thetownly.in)

Official website for **Townly** — Your Local Marketplace & Community Platform.

## Live Domain
- https://thetownly.in
- https://www.thetownly.in

## Features
- Fast, modern responsive landing page
- SEO-optimized with OpenGraph, Twitter cards, canonical tags
- Google Search Console ready with sitemap and robots.txt
- Deployed on Cloudflare Workers & Pages

## Development & Deployment

### Run locally
```bash
npx wrangler dev
```

### Deploy to Cloudflare
```bash
npx wrangler deploy
```
